# Antigravity Orchestra

Готовый набор кастомных агентов:

- orchestrator — главный агент
- architect — анализ и архитектура
- implementer — реализация
- reviewer — независимое ревью
- tester — тестирование

Скопируй папку `.agents` в корень своего проекта.

После этого открой `/agents` и выбери `orchestrator` как main agent.

Пример запроса:

Полностью проанализируй этот проект.
Используй architect для анализа архитектуры,
implementer для реализации,
reviewer для независимого ревью,
tester для проверки.
Распараллель независимые задачи.
Если reviewer или tester находят проблемы — отправляй задачу обратно implementer и повторяй проверку до исправления.
