# Научный Обнинск — интерактивная карта

Статический сайт о четырёх научных организациях Обнинска: ФЭИ, ОНПП «Технология», НПО «Тайфун» и обнинской площадке НИФХИ им. Карпова. Это тематическая подборка, а не полный реестр города.

Опубликованная версия: https://mgyodda.github.io/obninsk-map/

## Что есть на сайте

- Спутниковая карта с переключением на улицы, метками и списком организаций.
- Поиск по названию, адресу, исследованиям, разработкам, терминам и профессиям. Три тематических фильтра одновременно меняют список и метки.
- Карточки с научным профилем, историей, 24 примерами работ и разработок, источниками и фотогалереями. В проекте 25 локальных изображений.
- Просмотр на компьютере и телефоне, управление с клавиатуры и полноэкранное открытие карточек и фотографий.
- [Локальный каталог](catalog.html) с текстами и фотографиями для чтения без сети. Картографическая подложка и внешние источники требуют подключения.
- Интерфейс в стиле Material Design 3 с адаптивной компоновкой.

Координаты указывают территории организаций, а не проверенные проходные. Фотографии могут быть архивными. Источники и подписи указаны в карточках.

## Запуск

Откройте [страницу проекта](project.html) или запустите локальный сервер из корня папки командой `python -m http.server 8000`, затем перейдите на `http://localhost:8000/`. Сайт не требует сборки, базы данных и API-ключей.

## Файлы

- `index.html`, `style.css`, `material.css`, `app.js` — карта и интерфейс.
- `data.js`, `photos.js`, `images/` — сведения и изображения. При добавлении организации нужны уникальный `id`, координаты, источники и запись о фотографиях.
- `catalog.html`, `project.html`, `project.css` — автономный каталог и материалы проекта.
- `pptx/Карта_Обнинска.pptx` — исходная презентация; `output/Карта_Обнинска_обновлённая.pptx` — актуальная версия для защиты.
- `vendor/` — локальная библиотека Leaflet и её лицензия.

Все внутренние ссылки относительные, поэтому сайт работает в подкаталоге GitHub Pages. Для публикации разместите файлы в корне репозитория и включите Pages для ветки `main`.
