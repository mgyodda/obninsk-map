# Обнинск — карта предприятий

Статический сайт для GitHub Pages. Спутниковая карта Esri World Imagery с переключением на улицы OpenStreetMap, локальная библиотека Leaflet 1.9.4, интерфейс на русском. Сервер, ключи API и сборка не нужны.

## Использование

На компьютере наведите на метку: откроется карточка с описанием, фото и адресом. Нажатие приближает карту. На телефоне коснитесь метки или названия в списке. Фотография открывается крупно по нажатию. Escape закрывает фото или карточку. Метки и список доступны с клавиатуры.

## Публикация в GitHub Pages

1. Создайте публичный репозиторий `obninsk-map` и загрузите содержимое этой папки в его корень. `index.html` должен находиться именно в корне.
2. В репозитории откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.
4. Дождитесь завершения публикации. GitHub покажет URL вида `https://ВАШ-ЛОГИН.github.io/obninsk-map/`.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Локальный запуск

В этой папке: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

## Содержание и редактирование

`data.js` содержит 8 избранных организаций, их координаты, сведения и источники. Это не полный реестр предприятий города. Координаты взяты из опубликованных энциклопедических статей и обозначают территории, а не проверенные проходные. Дата проверки сведений — 14 сентября 2026 года. Фотографии, подписи и источники указаны в `photos.js`. Не заменяйте фотографии одной организации фотографиями другой.

Для добавления предприятия добавьте объект с уникальным `id` в `data.js` и соответствующее фото в `photos.js`. Список, номера меток и счётчик обновляются автоматически. `coords` — широта, затем долгота.

`index.html`, `style.css`, `app.js` — интерфейс. Все локальные ссылки относительные: сайт работает и в подкаталоге GitHub Pages.

Картографическая подложка и две фотографии Wikimedia требуют интернета. Две остальные фотографии включены в папку `images`. Тайлы запрашиваются по мере просмотра, без массовой предзагрузки; сохранена обязательная атрибуция OpenStreetMap. При сбое подложки список и карточки продолжают работать. При сбое фотографии доступна ссылка на её источник. Шрифт Google Fonts необязателен: предусмотрен системный запасной шрифт.

Leaflet распространяется по BSD-2-Clause, см. `vendor/LICENSE`. Права на фотографии принадлежат авторам; сведения о лицензиях и источниках показаны у каждой фотографии.
